## Deskripsi Repository
Repository ini dibuat sebagai wadah penyimpanan kode, catatan, dan dokumentasi dari kegiatan workshop mengenai penggunaan Artificial Intelligence (AI) dan manajemen *version control* menggunakan Git dan GitHub.

## Tujuan Repository
Tujuan kegunaan repository ini adalah untuk mendokumentasikan proses pembelajaran, mempraktikkan alur kerja Git (seperti add, commit, push), serta menyimpan hasil proyek sederhana yang dikembangkan selama workshop berlangsung.

## Dokumentasi Kegiatan Workshop

### Rangkuman Materi
Pada Day 1 Proyek Workshop, materi yang disampaikan berfokus pada dua hal utama:
1. **Prompt Engineering**: Cara memberikan instruksi (prompt) yang tepat kepada AI agar hasilnya relevan. Prompt yang baik terdiri dari 4 elemen: **Role** (peran AI), **Task** (tugas yang harus dikerjakan), **Context** (latar belakang masalah), dan **Format** (bentuk hasil yang diinginkan).
2. **Git & GitHub**: 
   - **Git** adalah sistem *version control* lokal untuk melacak perubahan file (mencakup Working Directory, Staging Area, dan Repository).
   - **GitHub** adalah platform *cloud* untuk menyimpan repository secara online.
   - Diajarkan juga berbagai *command* dasar seperti `git init`, `git add .`, `git commit -m`, `git push`, dan cara integrasi dengan VSCode menggunakan otentikasi SSH Key.

### Poin-Poin Penting yang Dipelajari
- Pentingnya memberikan konteks yang jelas kepada AI agar performa AI meningkat dan terhindar dari bias.
- Perbedaan mendasar antara Git (sistem lokal) dan GitHub (layanan hosting online).
- Alur kerja (workflow) penyimpanan kode, mulai dari *Working Directory* (tempat modifikasi file), masuk ke *Staging Area* (persiapan), hingga *Commit* ke repository.
- Cara melakukan *generate* SSH Key (`ed25519`) dan menghubungkannya antara komputer lokal (macOS/Windows) dengan akun GitHub agar proses *push/pull* lebih aman dan mudah.

### Pendapat Pribadi tentang Day 1 Proyek Workshop
Day 1 Proyek Workshop ini sangat praktikal dan informatif. Materi *prompt engineering* memberikan wawasan baru tentang bagaimana cara berkomunikasi dengan AI secara efisien sebagai *developer*. Selain itu, praktik langsung *setup* Git dan GitHub melalui terminal di VSCode sangat membantu memperkuat fundamental dalam kolaborasi dan manajemen kode ke depannya.
